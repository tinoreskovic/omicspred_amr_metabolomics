# Model and Nightingale trait metadata

`omicspred_validation.xlsx` is a compact version of the metadata required by these analyses for the 141 INTERVAL Study–trained genetic models for the prediction/imputation of Nightingale NMR metabolomic traits. It contains the OmicsPred accession, Nightingale trait abbreviation and name, trait group and subgroup, UK Biobank field ID, and the published UK Biobank and Multiethnic Cohort validation R² and Spearman rho values used for Figure 1.

The model and validation fields are from Supplementary Table 2 of the original [OmicsPred study](https://doi.org/10.1038/s41586-023-05844-9). The UK Biobank field ID is included in the same workbook so that the UK Biobank analysis uses a single model-to-trait mapping file.
