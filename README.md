# Genetic models for the prediction of Nightingale NMR metabolomic traits

This repository contains the original code used to train genetic models for the prediction/imputation of Nightingale NMR metabolomic traits with Mexico City Prospective Study (MCPS) data, internally validate them and compare them with INTERVAL Study–trained models, externally validate them among UK Biobank (UKB) and All of Us Research Program (AoU) participants of "admixed American" (AMR) genetic ancestries, and, also in AoU, perform association analyses of predicted metabolomic traits with diseases.

## Repository contents

- `mcps/validate_interval/`: validation of the INTERVAL-trained genetic models in MCPS, including the ancestry and subgroup comparisons used in the manuscript.
- `mcps/train_mcps_models/`: training of the new MCPS genetic models.
- `mcps/validate_mcps_models/`: validation of the MCPS-trained models in the withheld MCPS subset and comparison with the INTERVAL-trained models.
- `ukb/`: external validation among UK Biobank participants of AMR genetic ancestries.
- `aou/`: external validation and disease-association analyses among AoU participants of AMR genetic ancestries.
- `figures/`: code for the main and supplementary figures made in R.
- `metadata/`: the model, Nightingale trait and UKB field metadata used by the scripts.
- `config/env.example`: example configuration for the files that remain within each analysis platform.

The repository contains the code and the small model/trait metadata files required to run it. MCPS, UK Biobank and All of Us data are accessed within their respective analysis environments.

## Genetic models

The MCPS-trained models (genetic scores) developed in this study will be publicly accessible through the [OmicsPred portal](https://www.omicspred.org/) under accession codes OPGS3339470–OPGS3339610.

The INTERVAL Study–trained genetic models used in this study are publicly accessible through the [OmicsPred portal](https://www.omicspred.org/) under accession codes OPGS003419–OPGS003559.

## Running the code

The cohort-specific scripts are run within the corresponding analysis environment. Copy `config/env.example` outside version control, replace the example locations with those used in that environment, and export the variables before running a workflow. The included metadata workbook is found relative to the repository and does not require a separate path setting.

R and Python dependencies are listed in `environment.yml`. PLINK 2 and a platform-supported installation of `pgsc_calc` are also required for the relevant model-scoring steps.

The run order for each cohort is described in its subfolder README. The plotting scripts read the resulting summary-level tables from `OMICSPRED_RESULTS_DIR` and write the manuscript figures to `OMICSPRED_FIGURE_DIR`.
